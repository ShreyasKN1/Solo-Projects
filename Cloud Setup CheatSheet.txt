1. Spring Boot → AWS Lambda + API Gateway Deployment Steps
Project Setup


Create normal Spring Boot application.
Add dependencies:
aws-serverless-java-container-springboot3
aws-lambda-java-core

Create Lambda handler class:
implement RequestStreamHandler

Configure handler to bootstrap Spring Boot application.

Build
Run:
mvn clean package
Generate:
fat JAR
OR
ZIP package
AWS Lambda Setup


Go to AWS Lambda.

Create new Lambda function.
Choose:
Runtime = Java 21 (or your version)
Upload:

JAR
OR
ZIP

Configure handler:

com.example.StreamLambdaHandler implements requeststreamhandler-> handler.proxyrequest(inputstream,outputstream,context)

API Gateway Setup (Manual)

Go to Amazon API Gateway.
Create REST API.

Create resource:
/{proxy+}
Create method:
ANY
Enable:
Lambda Proxy Integration
Connect API Gateway to Lambda function.


Deploy API:
create stage (dev/prod)
Use generated API URL.
SAM / template.yaml Alternative
Instead of manual API Gateway setup:
create template.yaml
Add:
Path: /{proxy+}Method: ANY


Run:
sam deploy

SAM automatically creates:
API Gateway
Lambda integration
permissions
deployment








2. Spring Boot -> EC2 Deployment Steps
Build Project


Create Spring Boot application.
Run:
mvn clean package
Generate:
target/app.jar
EC2 Setup
Go to Amazon EC2.

Launch EC2 instance.


Choose:
Amazon Linux
OR
Ubuntu

Create/download key pair:
my-key.pem

Windows + PuTTY Setup
Open PuTTYgen.
Load .pem file.
Save generated .ppk file.
Security Group
Allow inbound ports:
22 -> SSH


8080 -> Spring Boot


80 -> HTTP (optional)


443 -> HTTPS

Connect Using PuTTY
Open PuTTY.
Add:
Hostname/Public IP

Go to:
Connection -> Data

Add auto-login username:
ec2-user
OR


ubuntu

Go to:
SSH -> Auth
Upload .ppk file.
Connect to EC2.
Java Installation

Verify:
whoami
Become root (optional):
sudo -i
Install Java:
Amazon Linux:


yum install java-21-amazon-corretto
Ubuntu:
apt install openjdk-21-jdk


Verify:
java -version
Transfer JAR

Option A (Preferred)
Use:
SCP
WinSCP
FileZilla
Transfer app.jar to EC2.



Option B (S3 + wget)
Upload JAR to Amazon S3 bucket.
Copy object URL.
Inside EC2:
wget <object-url>
Run Application
Run:
java -jar app.jar
Access:
http://PUBLIC_IP:8080

4. AWS Secrets Manager + Spring Boot Steps
Create Secret
Go to AWS Secrets Manager.
Click:
Store new secret
Choose:
RDS credentials
OR
Other type of secret
Add Secret Values
Add JSON:
{
  "username":"admin",
  "password":"mypassword"
}
Optionally add:
host
port
dbname
Configure Secret
Select encryption key.
Choose RDS instance (optional).
Add:
secret name
description
tags
Rotation
Enable automatic rotation (optional).
AWS automatically rotates:
DB password
secret value
Spring Boot Dependencies
Modern Preferred
Add:
spring-cloud-aws-starter-secrets-manager

Older Manual SDK Approach
Add:
AWS SDK
Secrets Manager SDK
Gson
AWS Credentials
Create:
Access Key
Secret Key

from:

AWS Account → Security Credentials
Configure locally:
aws configure
Fetch Secret
Modern Approach
Add:
spring.config.import=aws-secretsmanager:secret-name
Use values directly:
spring.datasource.username=${username}
spring.datasource.password=${password}
Manual SDK Approach
Create DTO class.
Fetch secret JSON string.
Convert using:
gson.fromJson()
Configure datasource:
DataSourceBuilder.create()
Set:
username
password
driver
URL
Build datasource.
