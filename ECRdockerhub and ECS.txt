ECR/dockerhub and ECS:

1. Package Spring Boot Application

From project root:

mvn clean package

Verify:

target/*.jar
2. Create Dockerfile

Project root:

FROM eclipse-temurin:21-jdk

COPY target/*.jar app.jar

ENTRYPOINT ["java","-jar","/app.jar"]
3. Build Docker Image
docker build -t springboot-app:v1 .

Verify image:

docker images
4. Login to AWS Console

Open:

AWS Console

Select region:

ap-south-1

(or preferred region)

5. Create ECR Repository

Go to:

Amazon ECR

Steps:

Elastic Container Registry
    ↓
Repositories
    ↓
Create Repository

Configuration:

Visibility: Private
Repository Name: springboot-app

Create repository.

6. Configure AWS CLI

Install AWS CLI.

Then:

aws configure

Provide:

Access Key
Secret Key
Region
Output format=json
7. Authenticate Docker to ECR

Inside ECR repository:

View Push Commands

Copy login command:

aws ecr get-login-password --region ap-south-1 | docker login --username AWS --password-stdin <account-id>.dkr.ecr.ap-south-1.amazonaws.com

Run it.

8. Tag Docker Image
docker tag springboot-app:v1 <account-id>.dkr.ecr.ap-south-1.amazonaws.com/springboot-app:v1

Example:

docker tag springboot-app:v1 123456789012.dkr.ecr.ap-south-1.amazonaws.com/springboot-app:v1

9. Push Docker Image to ECR
docker push <account-id>.dkr.ecr.ap-south-1.amazonaws.com/springboot-app:v1

Verify image appears inside ECR repository.

10. Create ECS Cluster

Go to:

Amazon ECS

Steps:

Clusters
    ↓
Create Cluster

Configuration:

Cluster Template: Networking only (Fargate)
Cluster Name: springboot-cluster

Create cluster.

11. Create Task Definition

Steps:

Task Definitions
    ↓
Create New Task Definition

Choose:

Launch Type Compatibility: Fargate/EC2
12. Configure Task Definition

Basic configuration:

Task Definition Name: springboot-task
Task Role: None
Network Mode: awsvpc
Task CPU: 0.5 vCPU
Task Memory: 1 GB
13. Add Container to Task Definition

Container configuration:

Container Name: springboot-container
Image URI: <ecr-image-uri>

Example:

123456789012.dkr.ecr.ap-south-1.amazonaws.com/springboot-app:v1

Memory limits:

Soft Limit: 512

Port mappings:

Container Port: 8080
Protocol: TCP

Add container.

Create task definition.

14. Create ECS Service

Open cluster:

springboot-cluster

Steps:

Services
    ↓
Create

Configuration:

Launch Type: Fargate
Task Definition: springboot-task
Service Name: springboot-service
Number of Tasks: 1
15. Configure Networking

Inside service creation:

VPC

Choose:

Default VPC
Subnets

Choose:

public subnets
Auto Assign Public IP
ENABLED

Critical for internet access.

16. Configure Security Group

Create new security group.

Inbound rules:

Type	Port	Source
Custom TCP	8080	0.0.0.0/0
HTTP	80	0.0.0.0/0
17. Create Service

Click:

Create Service

Wait until:

Tasks Running = 1
18. Get Public IP

Go to:

Cluster
    ↓
Tasks
    ↓
Running Task
    ↓
Networking

Copy:

Public IP
19. Access Application

Browser:

http://<public-ip>:8080

Example:

http://13.233.xxx.xxx:8080
Updating Application Later

After code changes:

Rebuild JAR
mvn clean package
Rebuild Docker Image
docker build -t springboot-app:v2 .
Tag
docker tag springboot-app:v2 <ecr-uri>:v2
Push
docker push <ecr-uri>:v2
Update ECS Task Definition

Create:

new revision
change image tag v1 → v2

Then:

Deploy New Revision

ECS replaces old container automatically.
