SNS-> fan out main purpose:

Open SNS.
Go to Topics.
Click Create topic.
Choose Standard/FIFO as appropriate.
Name:
order-events
Create separate SQS queues imagine three services like email, inventory and analytics.
->email-queue
->inventory-queue
->analytics-queue
Go to the SNS topic.
Choose Create subscription.
Protocol:
Amazon SQS
Select the appropriate queue.
Repeat for each queue.

EventBridge: event routing for event type/content


Open AWS Console -> EventBridge.
Go to Rules.
Click Create rule.
Give it a name:
order-event-router[example].
Select the appropriate event bus.
Choose Rule with an event pattern.
Define the event pattern.
For example:

{
  "source": ["my.order-service"],
  "detail-type": ["OrderCreated"]
}


Choose the target:
->SQS
->SNS
->Lambda
->another EventBridge bus


Configure required IAM permissions.
Create the rule.

The rules match events against an event pattern and route matching events to configured targets.
